## 推荐阅读顺序

1. **入门**：`wenhaolai/AI-Agent` — 跟你技术栈完全一致，教学定位，代码好读
2. **实战**：`travel-agent` — 三件套齐全，有 Docker 部署，功能完整
3. **深入 Agent**：`openAgent` — FastAPI + LangGraph 可视化工作流，最完整的 Agent 平台参考
4. **纯 Java 路线**：`fish-ai-agent` 或 `ai-code-helper` — Spring AI + Langchain4j，证明 Java 也能做 AI
5. **生产级参考**：`agent-service-toolkit` — FastAPI + LangGraph 最佳实践，架构设计典范
